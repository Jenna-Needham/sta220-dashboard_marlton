# sta220-dashboard_marlton

**Data**
Two of the files used for the dataset of this project are too large to be stored directly in this GitHub repository. The data can be downloaded from: [New Jersey Department of Education: School Performance Reports Downloadable Data]([url](https://www.nj.gov/education/spr/download/)), by downloading the 2024-2025 Performance Reports Database in Excel for both the School and District/State. 

After downloading the file, place it in the appropriate data folder within the local project directory so that the R script can access it. For example: 

data/njdoe_2024-2025_school or data/njdoe_2024-2025_district_state

The data file is stored locally in the project folder but it is not uploaded to GitHub. If this repository is used on another computer, the dataset must be downloaded again and placed in the same folder before running the analysis.
